# AGENTS.md — BEMBEL

Context for AI-assisted sessions in this repo. Humans: read CONTRIBUTING.md.

## What this is

Free iPhone city app for Frankfurt / Rhein-Main. iOS 18.5+, SwiftUI, three
targets (BEMBEL app, BEMBELWidgets extension, BEMBELKit local Swift package).
No backend, no third-party dependencies, no analytics, German-first strings.

## Locked decisions — do not relitigate

See docs/superpowers/specs/2026-08-13-hero-repositioning-design.md for the
current scope (the original kickoff prompt is archived at
docs/history/2026-06-kickoff-prompt.md). Highlights: the hero is the

`de.mauricejobst`; MIT code licence; selection principles are data readiness
first and AI-native development (ADR 0008).
Decisions with rationale live in docs/adr/ — read before proposing changes to

## Conventions

- One commit per ticket, message prefixed `BEM-XXX:`. Reference the GitHub
  Issue (`Closes #N`) in the PR, not in the commit — the issue body is the
  spec and the status; docs/BACKLOG.md only maps epics to issues. See
  CONTRIBUTING.md's "Workflow" section before closing or relabeling an issue.
- Verification: `make test` (BEMBELKit, runs on macOS — no simulator),
  `make build` (needs Xcode 16.4+), `make validate` (data schemas).
- The .pbxproj uses filesystem-synchronized groups (objectVersion 77): adding
  a file to App/ or Widgets/ adds it to the target — do not hand-edit target
  membership.
- `data/rings.json` and the copy in BEMBELKit Resources are generated by
  `scripts/generate_rings.py` — never hand-edit either; `make validate`
  enforces they match. The same applies to `data/bembeldata.json`
  (generated by `scripts/sync_bembel_data.py` from the published
  bembel-data bundle).
- Tests earn their keep (data layer, decoders, deep links, region filter) —
  no tests on SwiftUI view bodies, no TDD ceremony.
- Curated data rows: source URL mandatory, facts only, enforced by
  `scripts/validate_data.py`, not by convention.
- README.md's three numbers about `data/sources.json` (entry count, endpoints
  the sweep calls, tier-5 findings) are recomputed by `make validate`: the
  registry is the authority and the prose follows it. Add a source and the
  check names the new number — write that one down; never adjust a number to
  paper over the registry. Rewording those sentences fails the check by
  design: move the pattern in `README_CLAIMS` with the prose, or drop both.
- The Orte tab (`App/Features/Places/`) carries all three place datasets behind
  one segmented control — there is no Water feature folder any more (ADR 0009).
  `BEMTab` has five cases; adding a sixth pushes iPhone into a "More" overflow.
